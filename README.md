# Sistema de Controle de Estoque

Sistema web desenvolvido em equipe para gerenciamento de produtos e controle de estoque.

## Funcionalidades
- Cadastro de produtos
- Listagem de produtos
- Edição de informações
- Exclusão de produtos
- Controle de preços e quantidades

## Tecnologias
- Java
- Spring Boot
- Maven
- HTML
- SQLite

## Como executar
As instruções de instalação e execução serão documentadas após a verificação das dependências e configurações do projeto.
